# Dataset and License Policy

## Rules

1. Download third-party data only through documented scripts.
2. Keep raw downloads out of Git and out of release artifacts.
3. Store source name, source URL, license, attribution, and retrieval date in manifests.
4. Do not publish derived raw HTML, screenshots, credentials, cookies, or private traces.
5. Publish only code, taxonomy, normalized examples that the source license permits, synthetic data, and model artifacts after a license review.
