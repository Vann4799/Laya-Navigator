# Architecture

```text
Public trajectories + synthetic workflows
        ↓
Source adapters and license manifests
        ↓
Compact state normalizer
        ↓
Laya typed decisions
        ↓
API schema composer
        ↓
Browser agent / QA / MCP integrations
```

Laya predicts typed decisions. Deterministic code owns schema validation, graph aggregation, and workflow history bookkeeping.
